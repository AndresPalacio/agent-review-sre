02 / sre-better-harness

El ciclo de experimentación

Una cola persistente lanza procesos separados: el baseline del runner oficial y una ronda local propose / probe / compose.

Qué prueba esta demo. Se ejecutan las APIs, los frameworks y las herramientas sobre datos grabados. Las decisiones del modelo y las propuestas PPC están guionadas. Este modo no mide calidad del diagnóstico ni demuestra mejoras del prompt.

Caso compartido para la comparación y PPC: eks/001-oomkilled-crashloop. El baseline oficial utiliza seis casos fijos en tres particiones.
