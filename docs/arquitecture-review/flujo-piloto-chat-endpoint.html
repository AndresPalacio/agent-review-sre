Qué está funcionando hoy y qué es una representación

Implementado en el piloto

  • Panel local, HTTP /work y MCP /mcp/, sobre un mismo servicio.
  • Supervisor y dos hijos con Deep Agents; actualización, cancelación, revisión e idempotencia.
  • Agent Server ejecuta el trabajo. SQLite guarda identidad y comandos; no ejecuta los agentes.
  • Modelo offline determinista y datos sintéticos. Un modelo real y Decisions son configurables, pero falta validarlos con credenciales.

Cómo interpretar esta página

  • Es un recorrido educativo: no consulta el backend, no usa claves ni inicia investigaciones.
  • La vista de chat y sus respuestas se presentan de forma simplificada. Conectar un chat a este piloto es un paso posterior.
  • El chat existente del producto usa /v1/chat/threads/{id}/messages y su grafo anterior; no se conectó automáticamente a WorkService.
  • En producción habría que conectar telemetría real y completar autenticación y persistencia. A2A/Jira y Temporal no están implementados en este piloto.

Datos de ejemplo: p95 = 820 ms · errores = 8 % · logs de timeout y conexiones agotadas.
