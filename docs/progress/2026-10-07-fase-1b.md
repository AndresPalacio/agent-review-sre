# Cierre local de la fase 1b

El plan [fase 1b](../superpowers/plans/2026-10-07-fase-1b-dominio-de-incidentes.md)
quedó implementado en `fase-1b` y se integró en `main` por fast-forward hasta
`0b23bcd`. No hubo push ni despliegue. La carpeta ajena `.idea/` quedó sin tocar.

La revisión final independiente encontró cinco defectos importantes: citas mixtas
reales e inventadas, citas de llamadas fallidas, pistas de fuente equivocadas,
timestamps no normalizados en extracción libre y tipos de colección malformados.
Se reprodujeron con pruebas que fallaron y se corrigieron en `0b23bcd`. No hubo
hallazgos críticos ni menores. El revisor dejó fuera la verdad semántica de claims
(fase 2), entrega real a proveedores (fases siguientes), pruebas Postgres en su
entorno y comparación exhaustiva con el historial de OpenSRE.

Gate final antes del merge: `uv run ruff check .`, `uv run ruff format --check .`,
`uv run mypy`, `uv run lint-imports` y `uv run pytest -q -p no:cacheprovider`
con `FIN_GRAPH_TEST_DATABASE_URL` y `FIN_GRAPH_REQUIRE_POSTGRES=1`: **412 passed,
0 skipped**. El mismo pytest se repitió en `main` tras el fast-forward: **412 passed,
0 skipped**. Sin configurar Postgres, el gate anterior a las correcciones ejecutó
396 pruebas y omitió 2 de persistencia. Postgres local estuvo disponible para el
gate final.

Decisión: `NormalizedAlert` normaliza todos los timestamps a UTC para que tanto
webhooks como extracción libre cumplan el mismo contrato. Los parsers rechazan
colecciones con tipos incorrectos mediante `AlertParseError`; en el punto de entrada
esto permite la detección de otra fuente.
